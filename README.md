# GEMS AR — معرض الأحجار الكريمة

معرض تفاعلي ثلاثي الأبعاد للأحجار الكريمة والمعادن الثمينة، يعمل في المتصفح ويدعم الواقع المعزز (AR) على الجوال.
مشروع مقرر **CPIS-360**.

## المزايا

- **50 حجراً ومعدناً** في 6 تصنيفات:
  - **نفيسة**: الماس، الياقوت، الياقوت الأزرق، الزمرد، الألكسندريت.
  - **شفافة**: التوباز، الأكوامارين، الغارنيت، الزبرجد، التنزانيت، التورمالين، الإسبينل، المورغانيت، الزركون، الكونزيت، الإيوليت، الفلوريت، المولدافيت.
  - **كوارتز**: الجمشت، السترين، الكوارتز الصخري، الكوارتز المدخّن، الكوارتز الوردي، العقيق، الكارنيليان، الأونيكس، عين النمر، اليشب، الأفنتورين.
  - **زينة**: الفيروز، الأوبال، اللازورد، اليشم، الملكيت، حجر القمر، حجر الشمس، اللابرادوريت، الأمازونيت، الرودوكروزيت، اللاريمار، السبج.
  - **عضوية**: اللؤلؤ، الكهرمان، المرجان.
  - **معادن**: الذهب، الفضة، البلاتين، النحاس، البايرايت، الهيماتيت.
- **تصفية حسب التصنيف**، وبحث بالاسم في وضع AR المتعدد.
- **عرض ثلاثي الأبعاد** بالتدوير والتكبير، مع معلومات لكل حجر (صلابة موس، الكثافة، المنشأ).
- **وضع AR** لوضع الحجر في المكان الحقيقي عبر WebXR (أندرويد)، أو Scene Viewer، أو Quick Look (iPhone).
- **AR متعدد**: اختر من 2 إلى 4 أحجار، فتُدمج فعلياً في مشهد واحد بمكتبة three.js.
- **نقاط تفاعلية وشريط تحكم داخل AR**: معلومات، تبديل، تأثير توهج.
- **اختبار "اسألني"** لتخمين الحجر من خصائصه.
- **تعرّف بصورة (تجريبي)**: يقرأ لون الحجر من صورة، ويسأل عن الشفافية واللمعة والنقش، ثم يقترح أقرب 3 أحجار من الخمسين. الصورة تُحلَّل داخل الجهاز فقط ولا تُرفع.

## التشغيل

AR يحتاج **HTTPS**، وأسهل طريقة لذلك هي GitHub Pages:

1. من إعدادات المستودع افتح **Settings → Pages**.
2. اختر الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط من جوالك.

للتجربة على الكمبيوتر (عرض ثلاثي الأبعاد فقط، بدون AR):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> لا تفتح `index.html` مباشرة بنقرتين، لأن المتصفح يمنع تحميل النماذج من `file://`.

## هيكل المشروع

```
index.html     الصفحة
style.css      التنسيق
app.js         المنطق: القوائم، الاختبار، دمج النماذج
identify.js    التعرّف التقريبي بالصورة (تجريبي)
gems.js        بيانات الأحجار الـ 50 وأيقوناتها
models/*.glb   نماذج الأحجار ثلاثية الأبعاد
tools/         سكربت توليد النماذج
```

## إضافة حجر جديد

1. أضف سطراً للحجر في `gems.js`.
2. أضف له نموذجاً في `tools/build-models.mjs` (داخل `MODELS`)، ثم شغّل:
   ```bash
   cd tools && npm install && npm run build-models
   ```
   يُنشئ السكربت النماذج الناقصة فقط داخل `models/`. أو ضع ملف `.glb` جاهزاً باسم الحجر نفسه.

## التقنيات

[`<model-viewer>`](https://modelviewer.dev) للعرض وAR، و[three.js](https://threejs.org) لدمج النماذج في وضع AR المتعدد. تُحمَّل three.js عند الحاجة فقط.

## ملاحظات

- أزرار التحكم والبطاقات داخل AR تظهر في WebXR فقط. أما Scene Viewer وQuick Look فهما تطبيقا عرض خارجيان لا يعرضان عناصر الصفحة.
- المشهد المدموج يُبنى داخل المتصفح، لذلك يفتح عبر WebXR أو Quick Look، ولا يفتح عبر Scene Viewer.

## إخلاء المسؤولية

هذا مشروع جامعي تعليمي غير تجاري.

- **ميزة "تعرّف بصورة" تجريبية**، ونتيجتها تخمين تقريبي مبني على لون الصورة وإجابات المستخدم، وقد تكون خاطئة تماماً.
  هي ليست فحصاً ولا توثيقاً ولا تقييماً لنوع الحجر أو أصالته أو قيمته، ولا يجوز الاعتماد عليها في بيع أو شراء أو أي قرار.
  لمعرفة نوع الحجر وأصالته يجب الرجوع إلى مختبر معتمد للأحجار الكريمة.
- يُطلب من المستخدم الإقرار بذلك قبل أول استخدام، ويبقى التنبيه ظاهراً في كل مرة.
- لا تُرفع الصور ولا تُحفظ؛ تُحلَّل داخل متصفح المستخدم فقط. الشيء الوحيد المحفوظ على الجهاز هو تذكّر الإقرار.
- معلومات الأحجار (الصلابة، الكثافة، المنشأ) للتعليم العام، وقد تختلف بحسب النوع والمصدر.
- النماذج ثلاثية الأبعاد تمثيلية مبسّطة، ولا تعكس شكل أو لون أو حجم حجر حقيقي بعينه.
